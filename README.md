# 🔎 Roblox Searcher

A simple Python tool for searching Roblox users using their public information.

## ✨ Features

- 🔍 Search Roblox usernames
- 👤 Get the Roblox User ID
- 📛 Display username and display name
- 📅 Show account creation date
- 🔗 Get the Roblox profile link
- 🛡️ Uses public Roblox information only

## 💻 Installation

### 1. Install Python

Download Python from the official website:

https://www.python.org/downloads/

During installation, make sure to check:
   
text
☑ Add Python to PATH
2. Download the project

Clone the repository:

git clone https://github.com/YOUR-USERNAME/Roblox-Searcher.git

Then enter the project folder:

cd Roblox-Searcher
3. Install the required library

Run:

pip install -r requirements.txt
4. Start the program

Run:

python roblox_searcher.py
🚀 Usage

You can start the program with:

python roblox_searcher.py

Then enter the Roblox username you want to search.

You can also provide the username directly:

```python roblox_searcher.py YOUR_USERNAME```

Replace YOUR_USERNAME with the Roblox username.

📋 Information Retrieved

The tool can display:

Username
Display Name
User ID
Account creation date
Ban status
Roblox profile URL
